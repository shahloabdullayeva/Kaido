How drivers use it

{{ connected }} truck{{ '' if connected == 1 else 's' }} connected
  1. Make a Telegram group for the truck, add the Kaido bot, and send /truck with the code from the truck's page.
  2. The driver sends /unit once so Kaido knows who they are.
  3. When the tank gets low, Kaido posts the best 3 stops ahead: price after discount, pump price, savings, parking, showers, map link. The driver taps Take on a stop or Skip with a reason.
  4. Kaido matches the EFS receipt and learns: skipped brands stop showing up, favourite brands go first.

Commands in the group: /fuel best stops now · /fuelprefs reminder level, must-haves, brands · /fuelweek last week's report card.
