# Reefer unit issues
Refrigerated trailers: Thermo King and Carrier units, alarms, temperature problems.
::: issue Reefer will not hold temperature | stop
looks: Box temperature drifting away from the set point; unit running all the time.
why: Low refrigerant, dirty condenser coil, iced evaporator (not defrosting), doors left open, door seals torn, air chute torn, load blocking airflow, unit in the wrong mode.
do: Check set point and mode (continuous vs cycle-sentry), doors closed, defrost. Call reefer service; a lost load is a large claim.
:::
::: issue Reefer alarm code | soon
looks: Alarm light on the reefer panel, code on the display, Samsara or reefer telematics alert.
ask: The exact code number, set point, return and discharge air temperatures, fuel level.
do: Look up the code for the unit (Thermo King and Carrier have different lists). Common: low fuel, high engine temperature, low oil pressure, sensor faults, defrost failure.
:::
::: issue Reefer will not start | soon
why: Reefer fuel empty (separate tank), reefer battery dead, glow plugs, fuel filter, shutdown alarm active.
do: Check fuel and battery. Clear alarm and restart once. Then service.
:::
::: issue Reefer low on fuel | soon
looks: Reefer fuel gauge under 1/4.
do: Fuel at the next stop. A reefer that runs dry may need priming.
:::
::: issue Evaporator iced up | soon
looks: Frost or ice block on the evaporator coil inside the front of the box; weak airflow; box warming.
do: Manual defrost. If it keeps icing, check the defrost system and door seals.
:::
::: issue Reefer service overdue | watch
looks: Engine hours past the service interval.
do: Service every 1,500-3,000 hours depending on unit ($400-900).
:::
