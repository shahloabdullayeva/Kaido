# Glossary
From the Fleet From Scratch manual.

## Overview
| Term | Meaning |
|---|---|
| ABS | Anti lock braking system |
| AMT | Automated manual transmission |
| APU | Auxiliary power unit: runs heat and AC while the engine is off |
| BASICs | The seven CSA safety score categories |
| CAC | Charge air cooler (intercooler) |
| CDL | Commercial driver's license |
| CPM | Cost per mile |
| CSA | Compliance, Safety, Accountability: FMCSA's carrier scoring |
| CVSA | Commercial Vehicle Safety Alliance: sets roadside inspection levels and out of service criteria |
| DEF | Diesel exhaust fluid, the blue cap tank |
| Derate | ECM cuts power and speed because of a fault |
| DOC | Diesel oxidation catalyst |
| DOT | Department of Transportation; also the carrier's USDOT number and the tire date code |
| DPF | Diesel particulate filter |
| DVIR | Driver vehicle inspection report |
| ECM | Engine control module, the engine's computer |
| EGR | Exhaust gas recirculation |
| ELC | Extended life coolant |
| ELD | Electronic logging device |
| FMCSA | Federal Motor Carrier Safety Administration |
| FMI | Failure mode identifier, the second half of a fault code |
| HOS | Hours of service |
| IFTA | International Fuel Tax Agreement |
| J1939 | The standard for heavy truck computer communication and fault codes |
| LF / RF / RRO | Tire positions: left front, right front, right rear outer |
| NOx | Nitrogen oxides, the pollutant EGR and SCR reduce |
| OOS | Out of service |
| PM | Preventive maintenance (PM A, B, C) |
| PMS / CBB / ABC | Pre-trip codes: properly mounted and secure / cracked, bent, broken / abrasions, bulges, cuts |
| psi | Pounds per square inch (air and tire pressure) |
| Regen | Burning soot out of the DPF (passive, active, parked) |
| Reefer | Refrigerated trailer |
| SCR | Selective catalytic reduction |
| SPN | Suspect parameter number, the first half of a fault code |
| Tandem | Two axles together |
| VIN | 17 character vehicle identification number |
| 6x4 | Six wheel ends, four driven: the standard highway tractor |
